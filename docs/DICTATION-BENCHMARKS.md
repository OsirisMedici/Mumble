# Dictation apps to benchmark against Karen Voice

Checked November 9, 2026 against vendor documentation and public download listings. These are five specialist dictation apps selected for their relevance to Karen Voice. The order reflects which products to study first. Comparable worldwide usage figures and independent tests of speed and accuracy were unavailable for this comparison.

| App | Available platforms | What to study |
| --- | --- | --- |
| 1. Wispr Flow | macOS, Windows, iPhone, Android | A guided way to choose writing styles for different kinds of apps. Its snippets expand a spoken phrase into saved text. Flow requires an internet connection for transcription. [Product guide](https://docs.wisprflow.ai/articles/2772472373-what-is-flow), [Styles](https://docs.wisprflow.ai/articles/2368263928-how-to-setup-flow-styles), [Snippets](https://docs.wisprflow.ai/articles/5784437944-create-and-use-snippets) |
| 2. Superwhisper | macOS, Windows, iOS, Android and Linux on Wayland | Named modes pair a speech model with optional cleanup and can activate automatically in selected apps or sites. It offers both local and cloud speech models. Linux launched November 3. [Downloads](https://superwhisper.com/download), [Linux release](https://superwhisper.com/blog/linux), [Modes](https://superwhisper.com/docs/modes/modes), [Models](https://superwhisper.com/models) |
| 3. Aqua Voice | macOS, Windows, iPhone, Android | A benchmark for technical terms. Its optional desktop Deep Context setting extracts relevant vocabulary from a screenshot at the start of dictation. Its dictionary and custom instructions also help shape the output. [Platform and feature guide](https://aquavoice.com/guide), [Deep Context](https://aquavoice.com/deep-context) |
| 4. Monologue | System-wide on Mac, iPhone and iPad, with an Apple Watch companion | When the target changes or can’t accept paste, Monologue says it puts the transcript on the clipboard and shows “Copied.” Mac can transcribe offline with a downloaded model. Its smart cleanup, context formatting and sync require a connection. [Dictation guide](https://www.monologue.to/dictation) |
| 5. VoiceInk | macOS, with a separately distributed iPhone and iPad companion | The closest open-source Mac comparison in this list. Local models are available, and modes can switch based on the active app or website. The vendor describes the mobile companion as a beta and links to a live App Store listing. [Mac source](https://github.com/beingpax/VoiceInk), [Mode triggers](https://tryvoiceink.com/docs/mode-triggers), [Mobile companion](https://tryvoiceink.com/ios) |

## Where Karen Voice stands

Karen Voice already has local speech recognition, configurable shortcuts, live previews for supported models, custom words, history with copy and retry, and a tray action to copy the last transcript. Optional post-processing supports custom prompts and is off by default. Public installers are for macOS. [README](../README.md), [English UI copy](../src/i18n/locales/en/translation.json), [Tray actions](../src-tauri/src/tray.rs)

On one Mac with Audio Feedback off, six short Fn holds produced text. Five correctly transcribed “Blue.” The app logged paste completion 0.51–1.17 seconds after key release, and TextEdit showed five instances of the expected word. This session measured one setup and did not test competing apps.

## Gaps to investigate first

1. **Recover at the moment something goes wrong.** Karen shows errors for recording, transcription and paste exceptions. An empty final result dismisses the overlay, and the copy and retry controls live elsewhere. Give the user a clear outcome when no speech is recognized and a direct way to copy or recover a transcript when it exists. Monologue’s clipboard fallback is the closest comparison. [Karen output handling](../src-tauri/src/actions.rs), [Karen error handling](../src/App.tsx), [Monologue paste recovery](https://www.monologue.to/dictation)
2. **Let people try a first dictation during setup.** Karen already guides users through model selection and permissions. Add a practice field that uses the real shortcut and shows whether the mic, recognition and text insertion worked. Keep model choices and advanced controls available without making them the starting point for everyday use. [Model setup](../src/components/onboarding/Onboarding.tsx), [Permissions setup](../src/components/onboarding/AccessibilityOnboarding.tsx), [Monologue release notes](https://www.monologue.to/changelog)
3. **Make output presets easy to pick.** Build on Karen’s custom prompts to offer an explicit choice such as plain dictation, work chat or email. An opt-in rule could pick a preset from the active app without requiring screen capture. [Karen post-processing settings](../src/components/settings/post-processing/PostProcessingSettings.tsx), [Superwhisper modes](https://superwhisper.com/docs/modes/modes), [VoiceInk app triggers](https://tryvoiceink.com/docs/mode-triggers)

For a fair speed and reliability comparison, run the same short phrases, client names and longer passages on the same Mac and microphone. Include trials after idle, with the model already loaded, and after switching target apps. Record the text that actually appeared, the time from key release to visible insertion, and whether the app let the user recover a missed paste. Keep timing and recognition accuracy as separate results.
