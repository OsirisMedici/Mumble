# Mumble 0.1.0

The first public preview. Local dictation, configurable shortcuts, model downloads and transcript history, with the Mumble name and Grove green palette.

Mac downloads are ad-hoc signed and are not Apple notarized. Updates are manual through our GitHub releases.

The app is now called Mumble. Existing settings, models and recordings keep the same storage location. The icon now uses the rounded Mumble “m” mark.
